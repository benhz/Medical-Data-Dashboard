## 长期目标

### 科学目标
```
建立数据构建的完整理论体系,
像操作系统、数据库一样,
成为计算机科学的基础学科。
```

### 工程目标
```
让数据构建从"手工艺"变成"工业化",
从"专家依赖"变成"标准流程",
从"一次性"变成"可持续"。
```

### 社会目标
```
让AI系统的数据基础更可信、更公平、更安全,
推动负责任AI的发展。
```
