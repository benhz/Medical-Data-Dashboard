# 医疗图像应用案例

## 任务定义

**场景**: 肺部X光片疾病分类(正常/肺炎/肺结核/肺癌)

## 核心学科

- **D2. 数据分布**: 风险分布(罕见病过采样)
- **D6. 标注**: 专家标注,双盲审核
- **D9. 数据治理**: HIPAA合规,去标识化

## 数据构建要点

### 1. 专家标注 (D6)

```
- 标注者: 3位放射科医生(5年+经验)
- 流程: 独立标注 → 讨论一致 → 主任医师最终审核
- IAA: 0.92(Fleiss' Kappa)
```

### 2. 分布设计 (D2)

```python
# 自然分布
natural_dist = {
    '正常': 70%,
    '肺炎': 20%,
    '肺结核': 7%,
    '肺癌': 3%
}

# 任务分布(平衡+风险)
task_dist = {
    '正常': 5000,
    '肺炎': 2000,
    '肺结核': 2000,  # 过采样
    '肺癌': 2000     # 过采样
}
```

### 3. HIPAA合规 (D9)

```python
# 去标识化
def deidentify_dicom(dicom_file):
    # 移除患者信息
    dicom_file.PatientName = ""
    dicom_file.PatientID = hash(dicom_file.PatientID)
    dicom_file.PatientBirthDate = ""

    return dicom_file
```

## 结果

- 数据集: 11,000张(去标识化)
- 质量等级: DQ-4(专家标注,IAA>0.9)
- 模型性能: 平均准确率92%, 肺癌召回率90%

## 关键经验

1. **专家标注必要**: 医疗任务必须专家参与
2. **合规优先**: HIPAA去标识化是前提
3. **风险分布**: 罕见病必须过采样,否则召回率低
