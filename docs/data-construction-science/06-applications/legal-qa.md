# 法律问答应用案例

## 任务定义

**场景**: 法律咨询问答系统

## 核心学科

- **D1. 任务建模**: 问答任务,准确率+可解释性
- **D6. 标注**: 律师标注,引用法条
- **D9. 数据治理**: 敏感信息脱敏
- **D10. 知识工程**: 法律知识图谱

## 数据构建策略

### 1. 知识图谱构建 (D10)

```python
# 法律知识图谱
legal_kg = KnowledgeGraph()

# 添加法律条文
legal_kg.add_entity('刑法第234条', type='LAW')
legal_kg.add_entity('故意伤害罪', type='CRIME')
legal_kg.add_relation('刑法第234条', 'defines', '故意伤害罪')

# 添加案例
legal_kg.add_entity('案例001', type='CASE')
legal_kg.add_relation('案例001', 'cites', '刑法第234条')
```

### 2. 律师标注 (D6)

```
- 标注者: 执业律师(3年+)
- 标注内容:
  ├─ 问题分类(民事/刑事/行政)
  ├─ 答案文本
  ├─ 引用法条
  └─ 置信度
```

### 3. 数据脱敏 (D9)

```python
def anonymize_legal_case(case):
    # 替换真实姓名
    case = re.sub(r'[张王李赵]\w{1,2}', '某某', case)

    # 脱敏地址
    case = re.sub(r'\d+号', 'XX号', case)

    return case
```

## 结果

- 问答对: 5,000条
- 知识图谱: 1,000+法条, 500+案例
- 答案准确率: 85%
- 法条引用准确率: 92%

## 关键经验

1. **知识图谱必要**: 单纯QA不够,需要结构化知识
2. **律师标注**: 法律任务必须专业人士
3. **可解释性**: 必须引用法条,不能只给答案
